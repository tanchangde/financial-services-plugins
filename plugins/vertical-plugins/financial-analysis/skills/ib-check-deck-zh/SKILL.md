# 投行材料检查器

对演示文稿进行全面的四个维度质量控制。通读每一页幻灯片，然后报告发现。

## 环境检查

本技能在 PowerPoint 加载项和对话中都可使用。开始前先确认当前环境：

- **加载项** —— 从当前打开的演示文稿读取。
- **对话** —— 从上传的 `.pptx` 文件读取。

本技能只读取并报告，不做修改 —— 因此两种环境下的工作流完全相同。

## 工作流

### 读取演示文稿

提取每一页幻灯片的文字，并记录每段文字来自哪一页。每条发现都需要幻灯片级归因（"5 亿美元出现在第 3、8 页，但第 15 页是 4.85 亿美元"）。30 页的演示文稿很难可靠地放在工作记忆中 —— 把提取文本写入文件，供数字检查脚本处理。

脚本需要带幻灯片标记的类 Markdown 输入，格式如下：

```
## Slide 1
[第 1 页文字内容]

## Slide 2
[第 2 页文字内容]
```

视觉检查可先用 `pptx` 技能工作流把幻灯片转成图像。

### 1. 数据一致性

提取带幻灯片引用的数据：
```bash
python scripts/extract_numbers.py content.md --check
```

验证：
- 关键指标在所有幻灯片上一致（收入、EBITDA、倍数）
- 计算正确（总计、百分比、增长率）
- 单位一致（使用相同比例：百万vs十亿，% vs 基点）
- 单位格式一致（例如$M vs $MM，$B vs $Bn - 全程选择一种风格）
- 时间周期对齐（财年vs最近十二个月vs季度）

标记模式：
```
问题：收入不匹配
- 第3、8页：5亿美元
- 第15页：4.85亿美元（DCF输入）
操作：协调数据
```

### 2. 数据与叙事对齐

将声明映射到支持数据：
- 趋势声明 → 图表方向
- 市场地位声明 → 收入/份额数据
- 事实断言 → 验证准确性

标记矛盾：
```
问题：叙事与数据矛盾
- 第4页："利润率下降"
- 第7页图表：利润率18% → 22%
操作：更新叙事或验证数据
```

检查合理性（例如"1000亿美元市场中的第一名"但收入2亿美元 = 0.2%份额）。

### 3. 语言润色

扫描以下内容：
- 随意措辞（"非常好"、"很多"）
- 没有具体细节的模糊量词
- 缩写、感叹号
- 不一致的术语

请参阅[references/ib-terminology.md](references/ib-terminology.md)了解替换模式。

标记模式：
```
问题：随意语言（第12页）
- "这笔交易是板上钉钉的"
→ "这笔交易具有引人注目的价值主张"
```

### 4. 格式QC

审计每张幻灯片：
- **图表**：来源引用、坐标轴标签、图例
- **字体**：一致的字体、层级大小
- **数据**：一致的格式（1,000 vs 1K）
- **日期**：全程格式一致
- **脚注**：适当的来源和免责声明

## 输出

使用[references/report-format.md](references/report-format.md)中的模板组织结构。按严重程度分类：

- **关键** —— 数字不一致、事实错误、数据与叙事矛盾。这些会阻断向客户交付。
- **重要** —— 语言、缺失来源、术语漂移。应当修复。
- **次要** —— 字号、间距、日期格式。属于打磨项。

先讲关键问题。如果没有关键问题，明确说明 —— "未发现数字不一致"本身就是一条结论，而不是没有结论。
